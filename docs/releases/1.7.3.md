**Download:**
- `Zeus-Poseidon-macos-arm64.zip`: Apple Silicon Mac, macOS 11 (Big Sur) or later.
- `Zeus-Poseidon-macos-intel.zip`: Mac with an Intel processor, macOS 11 (Big Sur) or later.
- `Zeus-Poseidon-linux-x86_64.AppImage` and `Zeus-Poseidon-linux-aarch64.AppImage`: Linux (Ubuntu 22.04, Debian 12, Fedora 36 or later).

You need your own copy of the game: the GOG installer of *Zeus + Poseidon*, or the game installed with Steam.

## What is new

Three fixes, all by [@northdakota](https://github.com/northdakota): thank you!

- **R rotates a building's footprint again.** The in-game help says to turn the palace, the gatehouse, the horse ranch, the sanctuaries or the pyramids with R, and R did nothing. Each press now turns the footprint a quarter, even with the pointer still on a trackpad, and whatever the keyboard layout: with a Ukrainian, Russian or Greek layout, the letter keys now reach the game as on Windows ([#172](https://github.com/nic0lasm/zeus-poseidon-arm64/pull/172)).
- **Steadier speed on Mac.** The code the emulator translates was sometimes placed too far from the emulator itself in memory, and the same game then took about a sixth more processor time, from one launch to the next. It now always stays close ([#170](https://github.com/nic0lasm/zeus-poseidon-arm64/pull/170)).
- **Floating point as on Windows.** The emulated processor now starts with the floating-point settings of a Windows thread. Nobody has hit the difference, but an invalid calculation would have stopped the game where Windows goes on ([#171](https://github.com/nic0lasm/zeus-poseidon-arm64/pull/171)).

Saves and scenarios are unchanged: the ten replayed scenarios give the same frames and the same game state as before.

## First launch

- **Mac:** unzip, double-click **Zeus Poseidon.app**. The application is not notarized by Apple: open *System Settings → Privacy & Security* (on macOS 11 and 12: *System Preferences → Security & Privacy → General*), click **Open Anyway**, then pick your GOG installer or game folder.
- **Linux:** make the AppImage executable (`chmod +x`), run it.

Every archive and AppImage is built and self-tested by the CI; none contains a game file. Please report anything odd in an [issue](https://github.com/nic0lasm/zeus-poseidon-arm64/issues).
